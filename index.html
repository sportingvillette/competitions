Rafraîchir les données FFHB

Rafraîchissement automatique chaque dimanche soir. Pour forcer une mise à jour immédiate, renseigne ton jeton GitHub une fois (voir note en bas de page) puis utilise le bouton ci-dessous.

Mettre à jour SportsRégions

Pousse le contenu à jour (années de naissance, prix licence, championnat, poule, description) sur les 37 fiches équipe, et met à jour les pages "Planning entrainements" et "Calendriers, résultats, classements" du site club. Nécessite le même jeton GitHub que le rafraîchissement FFHB ci-dessus.

News "résultats du week-end"

Crée sur SportsRégions un brouillon de news (intro générée par IA + tableau des résultats + blocs photos/commentaires) pour le dernier week-end écoulé — reste "Hors ligne", à relire et publier toi-même depuis l'admin SportsRégions. Nécessite le même jeton GitHub que ci-dessus.
